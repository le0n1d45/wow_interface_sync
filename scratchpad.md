The plan for this project is to create an application that can be ran on any machine that takes 2 things:   
  
1) a github gist  
2) a github repository

it will utilize git via either stored credentials or ssh key to keep wow interface settings in-sync with the given github repository.  secondly, it will update the given gist with a proper [WoWUp](http://WoWUp.io) addon export string so the addons installed can be easily imported using wowup on a new machine.  
  
the settings for those addons can be synced down on a new machine using github.
